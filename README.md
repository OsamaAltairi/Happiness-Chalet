# Happiness Chalet - واحة الغروب

موقع تعريفي فاخر لشاليه Happiness Chalet مع هوية «واحة الغروب».

## المميزات

- تصميم RTL متجاوب مع جميع الأجهزة
- عرض صور الشاليه والخدمات والمرافق
- عرض أسعار الحجز بشكل واضح
- زر واتساب مباشر للاستفسار أو الحجز
- موقع ثابت بالكامل (Frontend فقط)
- لا يوجد Backend أو قاعدة بيانات
- لا يوجد نظام حجز إلكتروني معقد

## الأقسام

1. **Header** - شعار + قائمة تنقل + زر واتساب
2. **Hero** - صورة رئيسية + وصف مختصر
3. **عن Happiness** - نبذة عن الشاليه
4. **الصور والتجربة** - معرض الصور
5. **المرافق** - عرض المرافق المتاحة
6. **الأسعار** - جدول الأسعار مع ملاحظات
7. **العائلة** - قسم مخصص للعائلات
8. **واتساب** - قسم التواصل المباشر
9. **Footer** - معلومات الاتصال والشبكات الاجتماعية

## التثبيت

1. قم بتنزيل الملفات
2. افتح `index.html` في متصفحك
3. الموقع جاهز للاستخدام

## التخصيص

### تحديث معلومات الاتصال
افتح ملف `index.html` وابحث عن:
- `966500000000` - رقم الهاتف (توجد في 4 أماكن)
- `مرحبًا، أرغب في الاستفسار عن أسعار حجز شاليه Happiness.` - رسالة واتساب الافتراضية

### تحديث الأسعار
افتح ملف `index.html` وابحث عن قسم `الأسعار` لتعديل الأسعار.

### إضافة صور حقيقية
1. ضع صورك في مجلد `images/`
2. عدل خلفية القسم الرئيسي في `css/style.css`:
```css
.hero {
    background: linear-gradient(rgba(0, 0, 0, 0.7), rgba(0, 0, 0, 0.7)), url('../images/hero-bg.jpg');
}
```
