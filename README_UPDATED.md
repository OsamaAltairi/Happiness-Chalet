## 🔧 **كيفية التخصيص:**

### **1. تحديث معلومات الاتصال:**
- فتح `index.html` وتعديل:
  - أرقام الهاتف (4 أماكن)
  - روابط الشبكات الاجتماعية
  - العنوان الكامل

### **2. تحديث الأسعار:**
- تعديل جدول الأسعار في قسم `الأسعار`
- تحديث الملاحظات إذا لزم الأمر

### **3. إضافة صور جديدة:**
- وضع الصور في `images/happy/`
- تحديث HTML بإضافة الصور الجديدة

### **4. تحديث بيانات الطقس:**
- الحصول على API key من [OpenWeather](https://openweathermap.org/api)
- تحديث `apiKey` في ملف `script.js`

### **5. إضافة آراء عملاء جديدة:**
- نسخ هيكل `testimonial-card` وإضافة آراء جديدة

## 🚀 **كيفية تشغيل الموقع:**

### **الطريقة 1: محلياً**
1. افتح `index.html` في متصفحك
2. الموقع يعمل مباشرة بدون حاجة لسيرفر

### **الطريقة 2: رفع على استضافة**
1. رفع جميع الملفات على استضافة ويب
2. الموقع يعمل كموقع ثابت (Static)

### **الطريقة 3: كتطبيق PWA**
1. افتح الموقع في Chrome أو Edge
2. اضغط على "Install" في شريط العنوان
3. التطبيق يُثبت على جهازك
